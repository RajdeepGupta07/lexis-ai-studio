# Lexis AI Studio

Design a world-class, premium, responsive Legal AI platform frontend using Next.js, React, TypeScript, Tailwind CSS, and shadcn/ui.

The UI should feel modern, luxurious, clean, and trustworthy—not like a traditional government or legal website.

Use inspiration from:

- Harvey AI

- Perplexity AI

- ChatGPT

- Notion

- Vercel Dashboard

- Linear.app

- Stripe Dashboard

The design language should emphasize simplicity, professionalism, and premium quality.

DESIGN GOAL

---------------------------------------

The application should feel like a premium SaaS product worth thousands of dollars per year.

The UI must immediately communicate trust, intelligence, and professionalism suitable for lawyers, judges, legal researchers, corporate legal teams, and law firms.

Every component should be clickable, animated, visually polished, and accessible.

Focus on outstanding UX with modern cards, gradients, subtle glass effects, premium spacing, and elegant typography.

Avoid clutter. Prioritize clarity, usability, and a world-class user experience.
